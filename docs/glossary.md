# Glosario — DocuFlow

Términos técnicos usados en el proyecto.

| Término | Definición |
|---------|------------|
| **ADR** | Architecture Decision Record — documento que registra una decisión arquitectónica con su contexto y consecuencias. |
| **CQRS** | Command Query Responsibility Segregation — separación entre lectura y escritura. |
| **DDD** | Domain-Driven Design — enfoque de diseño guiado por el dominio. |
| **DTO** | Data Transfer Object — objeto para transferir datos entre capas. |
| **JWT** | JSON Web Token — estándar para transmitir información firmada. |
| **OCR** | Optical Character Recognition — reconocimiento óptico de caracteres. |
| **Outbox** | Patrón para garantizar publicación de eventos junto con la transacción. |
| **RBAC** | Role-Based Access Control — control de acceso basado en roles. |
| **SLO** | Service Level Objective — objetivo medible de nivel de servicio. |
| **Soft delete** | Eliminación lógica: se marca el registro sin borrarlo físicamente. |
