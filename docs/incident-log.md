# Incident Log — DocuFlow

Registro de errores significativos y sus soluciones.

## Formato

### INC-XXX — Título del incidente

- **Fecha:** YYYY-MM-DD
- **Descripción:** ¿Qué ocurrió?
- **Causa raíz:** ¿Por qué ocurrió?
- **Solución:** ¿Cómo se resolvió?
- **Prevención:** ¿Qué prueba, validación, documentación o proceso evita que se repita?

---

_(se completa cuando ocurra el primer incidente)_
