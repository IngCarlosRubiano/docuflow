# Technical Debt — DocuFlow

Deuda técnica registrada con motivo, impacto y condición de resolución.

## Formato

| ID | Tipo | Descripción | Motivo | Impacto | Condición de resolución |
|----|------|-------------|--------|---------|-------------------------|
| TD-001 | intencional | _(pendiente)_ | _(pendiente)_ | _(pendiente)_ | _(pendiente)_ |

## Tipos

- **intencional:** decisión consciente con fecha de revisión.
- **accidental:** surgida por descuido o prisa.
- **trade-off:** consecuencia aceptada de una decisión arquitectónica.
- **temporal:** código de andamiaje con fecha de eliminación.
- **limitación conocida:** el sistema no cubre un caso a propósito.
