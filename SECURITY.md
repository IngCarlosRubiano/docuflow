# Security Policy

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en este proyecto, por favor
**no abras un issue público**. Envía un correo a:

**carlos.rubiano.olaya@gmail.com**

Incluye:

- Descripción del problema
- Pasos para reproducirlo
- Impacto potencial
- Versión afectada

Recibirás una respuesta en un plazo oportuno.

## Versiones soportadas

Este proyecto está en desarrollo activo. Solo la última versión
publicada (`vX.Y.Z` más reciente) recibe parches de seguridad.
